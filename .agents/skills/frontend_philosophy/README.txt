This folder contains a reusable frontend design skill and supporting framework.
The application repository is not part of this deliverable and must not be
modified as part of work on this skill.

Start with SKILL.md. Use references/patterns.md for interaction decisions,
assets/foundation.css for adaptable styles, and assets/example.html for a
standalone searchable/sortable application example. Open example.html in a
browser; it requires no build, dependencies, or network access.
